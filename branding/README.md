Public brand assets for **Unifying Systems LLC**. Served via GitHub Pages at
`https://try-this.github.io/branding/`.

## Contents

| File | What it is | Direct link |
|------|------------|-------------|
| `us_lockup.png` | Primary logo — gradient "un" lockup, transparent background (720×270). Used live in Mark's email signature. | https://try-this.github.io/branding/us_lockup.png |
| `UnifyingSystems_Website_Suite_2026-08-20.zip` | Complete website artifact suite (2.3 MB) — everything a developer needs to wire up favicons, social cards, and logos. | https://try-this.github.io/branding/UnifyingSystems_Website_Suite_2026-08-20.zip |

## What's inside the website suite zip

- **favicons/** — `favicon.ico`, `favicon.svg`, PNGs 16→512, `apple-touch-icon` (180), `android-chrome` 192/512, full-bleed maskable (512), Windows `mstile` (150)
- **Social cards** — `og-image.png` (1200×630), `twitter-card.png` (1200×600)
- **Logo variants** — lockup, wordmark, and icon, each in light- and dark-background versions
- **Wiring files** — `site.webmanifest`, `browserconfig.xml`, `head-snippet.html` (paste into `<head>`), `HANDOFF.txt` (palette + usage notes)

### Quick install (for the developer)
1. Drop the `favicons/` folder at the site web root.
2. Paste the tags from `head-snippet.html` into the site's `<head>`.
3. Use the light/dark logo variants per background as needed.

## Brand palette
- Theme / primary: `#6E46E5`
- Background: `#F7F5FB`
- Gradient "un" mark: light lavender → deep violet

All assets derive from the approved hi-res gradient "un" lockup. These are raster PNGs; a true vector (SVG) trace of the "un" ribbon can be produced on request.
